# Bundled local OCR data

These Apache-2.0 Tesseract fast LSTM models allow local English, Hindi and Malayalam OCR. No customer images are sent to the model download host. The app reads these files locally with runtime downloads disabled.

Source: https://github.com/tesseract-ocr/tessdata_fast (downloaded 27 October 2026). Files were gzip-compressed locally; the committed bytes are pinned by the hashes below. License: LICENSE.txt in this folder.
